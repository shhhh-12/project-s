# CallScore visual system

**Mode:** Operate. A manager needs to upload, understand progress, and act on coaching without visual noise.

**Direction:** Black workbench with electric aqua as the single active signal. The interface is intentionally spare: broad dark surfaces, white reading panes, narrow technical dividers, Roboto typography, and no decorative gradients. Aqua appears only where an action is available, a state is active, or a result is positive.

**Tokens:** ink `#07090B`, panel `#101419`, elevated `#171C22`, paper `#F7F9FB`, aqua `#12E8E0`, aqua-deep `#00BFB9`, muted `#98A4B3`, line `#26313C`, error `#FF6B6B`.

**Motion:** 160ms press/hover feedback; 260ms drawers and tab transitions; a text-led pulse during processing; all non-essential motion is disabled under `prefers-reduced-motion`.

**Responsive behavior:** one column through 767px, a compact results rail from 1024px; controls remain 44px minimum. Mobile navigation uses icon-first actions; desktop exposes labels.
